# AI求职助手 - 浏览器扩展 (Chrome / Edge MV3)

将 Boss 直聘页面中的岗位信息无感捕获并同步至 AI 求职助手本地后端，执行深度匹配评分与 HR 活跃度分析，辅助求职者科学决策是否值得沟通投递。

> 💡 **跨平台兼容**：本扩展基于现代 Chromium Manifest V3 规范构建，原生兼容 **Google Chrome** 与 **Microsoft Edge**。

---

## 一、求职者使用指南

### 1.1 扩展安装

1. 打开浏览器扩展管理页面：
   - **Google Chrome**：访问 `chrome://extensions/`
   - **Microsoft Edge**：访问 `edge://extensions/`
2. 打开右上角 **“开发人员模式” (Developer mode)** 开关；
3. 点击 **“加载已解压的扩展程序” (Load unpacked)**；
4. 选择本项目根目录下的 `extension/` 文件夹；
5. 扩展加载完成，浏览器工具栏将出现 AI 求职助手图标。

---

### 1.2 单岗位深度分析 (手动模式)

1. 确保本地后端服务已启动（默认地址：`http://127.0.0.1:8000`）；
2. 打开 Boss 直聘任意岗位详情页，页面右下角将自动呈现 **AI 求职助手悬浮面板**；
3. 点击面板中的 **“发送到AI求职助手”**；
4. 插件将即时从后端获取分项评分、等级与投递建议；若综合评分达标，面板将显示“一键沟通”快捷入口。

---

### 1.3 本页批量自动筛选 (自动模式)

1. 打开 Boss 直聘搜索结果页（岗位列表页）；
2. 在右下角浮窗的“本页自动筛选岗位”区域按需配置策略：
   - **4 档场景化策略预设**：
     - **🛡️ 稳健防封**：新号/敏感期推荐，高拟人长延时（20~50秒），单日沟通上限 15 次，仅与 3 日内活跃 HR 沟通；
     - **⚖️ 标准平衡**（默认）：日常求职推荐，拟人化时延（12~30秒），单日沟通上限 25 次，适度主动沟通；
     - **⚡ 快速初筛**：仅批量打分推荐，强制关闭自动沟通，快速遍历（5~12秒），不限制 HR 活跃度；
     - **⚙️ 自定义**：在安全底线内自由微调各项参数；
   - **参数微调与安全底线**：
     - **匹配阈值**：默认 80 分（低于该分数的岗位自动略过）；
     - **扫描上限**：默认 30 个（单次任务安全上限 100 个）；
     - **本次沟通**：默认 5 个（单次任务安全上限 30 个）；
     - **单日上限**：默认 25 次（单日绝对安全硬顶 50 次）；
     - **时延抖动**：支持自定义最小/最大延迟（强制底线：最小延迟 $\ge 5$s，最大延迟 $\ge 10$s）；
     - **自动沟通开关**：**默认关闭**，勾选后达标岗位才主动打招呼；
     - **HR 活跃要求**：仅在线、3日内活跃、本周内活跃、本月内活跃、不限制；
3. 点击 **“开始自动筛选”**；
4. 插件将按序处理本页卡片：
   - 逐个激活岗位卡片并读取右侧详情；
   - 提取岗位要素发送后端进行 AI 分析；
   - 判定分数后自动归档到 Web 端的“插件捕获”数据中心；
   - **每个岗位处理完成后引入设定区间的拟人化随机时延**；
5. 筛选过程中支持随时 **暂停**、**继续** 或 **终止**。

---

### 1.4 安全防封号保护机制

针对招聘网站的反爬与行为风控机制，本扩展内置多重防封号保护网与安全红线：

1. **不可逾越的安全底线 (Hard Bounds)**：无论用户如何配置自定义参数，底层均强制执行安全限幅（最小延迟 $\ge 5$ 秒，最大延迟 $\ge 10$ 秒，单日沟通上限 $\le 50$ 次），彻底杜绝极端激进参数导致的瞬间封号；
2. **拟人化高斯时延**：每次请求与点击之间均加入高斯分布随机停顿，消除机械化周期性特征；
3. **单日沟通硬熔断**：单日累计沟通达到设定上限后强制熔断，终止一切自动化沟通操作；
4. **风控滑块与弹窗熔断**：一旦检测到页面出现极验滑块验证、短信验证码或“操作频繁”提示弹窗，立即自动暂停任务并醒目告警；
5. **严格不自动翻页**：坚持“单页扫描 + 人机配合”，翻页由用户手动触发，确保交互真实自然；
6. **双端无缝同步**：浮窗面板与浏览器 Popup 弹窗共享统一存储（`chrome.storage.local`），任何一处修改均实时双向同步。

## 二、开发者与维护者指南

### 2.1 DOM 选择器维护

当招聘网站改版导致岗位标题、公司或 JD 提取失败时，无需重构业务逻辑，仅需更新源码中的选择器配置：

1. 打开配置文件：`extension/src/config.js`；
2. 在 `SELECTORS` 对象中更新或追加匹配候选：

```javascript
export const SELECTORS = {
  jobTitle: ['.name', '.job-title', 'h1'],
  company: ['.company-info a', '.company-name'],
  salary: ['.salary', '.job-salary'],
  location: ['.text-city', '.job-location'],
  jobDescription: ['.job-sec-text', '.job-detail-section'],
  immediateChatBtn: ['.btn-startchat', '.op-btn-chat']
};
```

3. 若卡片定位选择器有变动，请调整 `extension/src/config.js` 中的 `JOB_CARD_SELECTORS` 数组。

---

### 2.2 扩展编译打包

本扩展源码位于 `extension/src/`，通过模块化打包编译输出生产产物 `extension/content.js`：

```bash
# 进入前端工程目录
cd frontend

# 执行扩展编译打包
npm run build:extension
```

打包完成后，在浏览器扩展管理页点击 **刷新按钮** 即可生效最新代码。

---

### 2.3 调试与日志分析

- 按 `F12` 打开浏览器开发者工具，切换至 **Console (控制台)**；
- 扩展的所有调度、捕获与时延日志均带有 `[AI求职助手]` 或 `[扫描]` 前缀，便于过滤追踪。
