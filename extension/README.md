# AI求职助手 - 微软 Edge 浏览器插件

将 Boss 直聘岗位信息发送到 AI 求职助手后端进行匹配分析，辅助判断岗位是否值得沟通。支持单岗位分析和本页自动筛选两种模式。

> 同时兼容 Chrome 浏览器（Chromium 内核，API 完全通用）。

## 功能

1. 在 Boss 直聘页面注入 AI 匹配面板
2. 自动提取页面中的岗位标题、公司、薪资、地点、JD 文本
3. 发送到后端进行 AI 匹配评分
4. 显示匹配分数、等级、推荐建议
5. 分数达标时提供"一键沟通"按钮
6. **本页自动筛选岗位** — 自动逐个分析当前搜索结果页岗位

## 安装（Edge）

1. 打开 **Edge 浏览器**，地址栏输入 `edge://extensions/`
2. 打开左侧"开发人员模式"开关
3. 点击"加载解压缩的扩展"
4. 选择 `extension` 文件夹
5. 插件安装完成

> **Chrome 用户**：操作相同，访问 `chrome://extensions/` 即可。

## 单岗位分析（手动模式）

1. 确保后端服务已启动（`http://127.0.0.1:8000`）
2. 在插件面板上传简历（或前端页面上传后插件自动同步）
3. 在 Boss 直聘搜索结果页点击某个岗位打开详情
4. 页面右下角 AI 求职助手面板中点击 **"发送到AI求职助手"**
5. 查看匹配结果，如推荐则点击 **"一键沟通"**

## 本页自动筛选（自动模式）

1. 打开 Boss 直聘搜索结果页（列表页，非详情页）
2. 在插件面板的"本页自动筛选岗位"区域设置参数：
   - **匹配阈值**：默认 85 分，低于此分数的岗位自动跳过
   - **扫描上限**：默认 20 个，最多 500 个
   - **沟通上限**：默认 3 个，单日硬上限 20 个（防封号保护）
   - **自动沟通**：默认关闭，需手动开启
3. 点击 **"开始自动筛选"**
4. 插件会：
   - 逐个点击左侧岗位卡片
   - 等待右侧详情加载
   - 提取岗位信息并发送后端分析
   - 根据分数决定推荐/跳过
   - 每处理一个岗位后随机等待 15-45 秒（高斯随机抖动，拟人化时延）
5. 过程中可随时 **暂停**、**继续**、**停止**
6. 完成后显示扫描总结和推荐岗位列表

### 自动沟通逻辑

- **默认关闭**，用户必须主动勾选"自动沟通"开关才会执行
- 仅对分数 ≥ 阈值的岗位尝试点击"立即沟通"
- 达到设置的最大沟通数量或单日硬上限后自动停止沟通
- 点击前会额外随机等待
- 仅点击文本包含"立即沟通"或"继续沟通"的按钮

## 安全限制与防封保护

1. 单次最多扫描 **500** 个岗位
2. 单日最多自动沟通 **20** 个岗位（硬熔断机制，超出强制停止，防止平台风控封号）
3. 自动沟通 **默认关闭**，用户必须主动开启
4. 用户必须主动点击"开始自动筛选"
5. **不自动翻页**，只扫描当前页
6. 不后台静默运行，页面关闭后自动停止
7. 扫描过程中可随时暂停或停止
8. 每个岗位之间有 **15 ~ 45 秒** 高斯随机拟人化时延与滑块/风控弹窗熔断检测

## 为什么只扫描当前页

- 避免被反爬机制检测
- 用户可以在扫描当前页时观察结果
- 翻页需用户手动操作，确保人机配合
- 单页通常已包含足够多的岗位（约15-30个）

## 注意事项

1. Boss 直聘页面 DOM 可能变化，如信息提取失败需更新 SELECTORS
2. 找不到"立即沟通"按钮时不会继续尝试，日志会提示用户手动处理
3. 所有数据仅发送到本地后端服务（`http://127.0.0.1:8000`）
4. 沟通后会自动通知后端更新状态

## 选择器配置

如果 Boss 直聘页面改版导致信息提取失败，请修改源码 `extension/src/config.js` 中的 `SELECTORS` 对象，并在 `frontend/` 目录下执行 `npm run build:extension` 重新编译：

```javascript
const SELECTORS = {
  jobTitle: [...]       // 岗位标题选择器
  company: [...]        // 公司名称选择器
  salary: [...]         // 薪资选择器
  location: [...]       // 地点选择器
  jobDescription: [...] // JD文本选择器
  immediateChatBtn: [...] // 立即沟通按钮选择器
};
```

### 岗位卡片选择器（自动筛选专用）

自动筛选功能使用 `getJobCards()` 函数查找岗位卡片，该函数内置多个候选选择器：

```javascript
'.job-card-wrapper', '.job-card-body', '.job-card',
'.job-list-box li', '.job-list-box .job-item',
'[class*="job-card"]', '.search-job-result li',
'.job-primary', '.job-info',
```

如果 Boss 页面改版导致找不到卡片，请修改 `getJobCards()` 中的候选选择器列表。

## 调试

1. 按 F12 打开 DevTools → Console 查看日志
2. 所有扫描操作都有 `[AI求职助手]` 或 `[扫描]` 前缀
3. 面板内的实时日志区域也会显示操作记录
